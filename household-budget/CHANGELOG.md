# Changelog

## [0.1.0] - 2026-08-19

### Added

- Mobile-first household budget setup and current balance cards.
- Separate bank-backed online and cash-backed offline expense entry.
- Daily spending totals and reconstructed bank/cash closing balances.
- Funds additions, six-month transaction retention, spending chart, and activity history.
- SQLite local development plus Supabase PostgreSQL deployment configuration.

### Security

- Exact integer money arithmetic, input validation, atomic balance updates, secret-safe errors, and restricted PostgreSQL public API roles.
